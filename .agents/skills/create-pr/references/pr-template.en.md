# English PR template

Replace the guidance with facts about the change. Record commands and observed results; explain checks that were not run. Omit risks and related issues when they do not apply.

```markdown
## Changes

Explain the problem or request and the resulting behavior.

## Implementation

- Details and decisions that help reviewers assess the change

## Validation

- `command executed`: observed result
- Checks not run and why, if any

## Risks and limitations

- Known impact, remaining limitations, or required rollout steps

## Related issues

Relevant issue links (use Closes only when the relationship and intent to close are established)
```
