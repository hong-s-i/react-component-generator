# 한국어 PR 템플릿

아래 틀을 실제 변경으로 채운다. 안내 문장은 본문에 남기지 않는다. 검증은 명령과 실제 결과를 적고 미실행 이유를 밝힌다. 위험·관련 이슈 항목은 해당할 때만 남긴다.

```markdown
## 변경 내용

문제 또는 요청과 변경 후 동작을 설명한다.

## 주요 구현

- 리뷰에 필요한 구현 내용과 선택 이유

## 검증

- `실행한 명령`: 실제 결과
- 미실행 검사와 이유(해당하는 경우)

## 위험 및 제한

- 알려진 영향, 남은 제한, 배포 시 필요한 작업

## 관련 이슈

관련 이슈 링크(실제 연결이 있고 종료 의도가 확인된 경우에만 Closes 사용)
```
